# Afrobeuty - Luxury Beauty Salon

Nairobi Elegance is a premium, modern web application for a luxury beauty salon based in Nairobi. It features a stunning UI, seamless navigation, and a focus on user experience.

![Hero Section](https://images.unsplash.com/photo-1560066984-138dadb4c035?w=1200&q=80)

## ✨ Key Features

- **💎 Boutique UI/UX**: A highly professional design using glassmorphism, smooth gradients, and micro-animations.
- **📅 Smart Booking System**: A comprehensive booking form with service selection (including duration and price), date/time picking, and a summary panel.
- **🛍️ Integrated Store**: A professional product catalog with category filters, "Sale" badges, and a custom quantity selector.
- **🖼️ African Hairstyle Gallery**: A curated gallery featuring African hairstyles and people, complete with customer reviews and star ratings.
- **🔔 Custom Toast Notifications**: Non-intrusive GUI notifications for shopping cart actions, replacing standard browser alerts.
- **📱 Responsive by Design**: Fully optimized for mobile, tablet, and desktop views. The store grid automatically adjusts to 2 columns on mobile.
- **🔍 Advanced Navbar**: A sticky, glassmorphism-effect navigation bar with an integrated search system and interactive "Book Now" call-to-action.

## 🚀 Tech Stack

- **Frontend**: [React.js](https://reactjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Routing**: [React Router](https://reactrouter.com/)

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone [repository-url]
   cd salon-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📂 Project Structure

```text
src/
├── assets/         # Images and static assets
├── components/     # Reusable UI components (Navbar, Footer, ProductCard, etc.)
├── pages/          # Full-page components (HomePage, StorePage, BookingPage, etc.)
├── App.jsx         # Main application shell and routing
├── index.css       # Global styles and Tailwind directives
└── main.jsx        # Application entry point
```

## 🎨 Design Principles

- **Premium Aesthetics**: Using a color palette of Pink, Purple, and Deep Grays to convey luxury.
- **Accessibility**: Semantic HTML and clear focus states.
- **Performance**: Optimized image loading and minimal CSS footprint via Tailwind.
